# ElimuPlus

Learn. Practice. Grow.

Initial front-end foundation for the ElimuPlus learning platform.

## Current build
- Professional responsive homepage
- Education pathway cards
- Short courses section
- Books/personal development section
- Practice and examinations section
- Teacher network section
- Student membership section
- Placeholder public pages
- Student/Teacher/Admin dashboard placeholders
- Generated ElimuPlus logo

## Planned backend
Supabase Auth + PostgreSQL + Storage + Row Level Security.

## Planned app
Android app using React Native/Expo, connected to the same backend.

## Important access rule
Teachers can join the teaching side for free, but a teacher account does not automatically unlock paid student content such as premium books or courses. Paid access will be controlled by backend entitlements.
